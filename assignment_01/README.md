# Lab Assignment 01: Student Portal

A clean, semantic academic student portal built with pure **HTML5** and introductory **CSS**.

## 📖 Features
- **Student Profile Table**: Student details with `<th>` headings and Top Performer badge
- **Skills List**: Unordered list (`<ul>`) of 6 core technologies
- **Weekly Schedule**: Monday–Friday timetable with alternating row colors
- **Course Registration Form**: Text input, email, dropdown, radio buttons, checkboxes, submit & reset
- **CSS Selectors Demonstrated**: element (`body`, `h1`), class (`.highlight`, `.badge`), ID (`#student-name`)

## 🚫 Rules Obeyed
- ✅ Pure HTML5 + introductory CSS only
- ❌ No Flexbox
- ❌ No CSS Grid
- ❌ No JavaScript
- ❌ No CSS frameworks

## 🚀 How to View
Open `index.html` directly in any browser, or visit the GitHub Pages link from the main README.
