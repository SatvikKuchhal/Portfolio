# Lab Assignment 02: Flexbox Quest (Mini Game UI)

A fully playable game-themed UI built exclusively with **CSS Flexbox** — no CSS Grid, no `position: absolute/fixed`, no JavaScript.

## 📖 Features
- **Game Header**: Flexbox row with Lives, Coins, Level, Bonus Score, and control buttons
- **Game Area**: Column flex layout with floating platforms, player sprite, and collectible stars
- **Control Panels (3-panel row)**: D-pad Controls, Inventory (flex-wrap), and Quest tracker — each using `flex: 1`
- **Educational Display Spotlight**: Visual cards showing `block`, `inline`, `inline-block`, `flex` behaviour
- **Responsive**: `@media (max-width: 768px)` stacks panels vertically

## 🚫 Rules Obeyed
- ✅ CSS Flexbox **only** for layout
- ❌ No CSS Grid
- ❌ No `position: absolute` or `position: fixed`
- ❌ No JavaScript
